# API Testing Tool

A browser-based API testing tool built with React and TypeScript for sending HTTP requests and inspecting API responses.

## Features

* Support for GET, POST, PUT, PATCH, and DELETE requests
* Custom request headers
* JSON request body support
* Response status display
* Response time measurement
* JSON response formatting
* Copy API response
* Request history
* Clear response and history
* Error handling
* Responsive user interface

## Technologies Used

* React
* TypeScript
* JavaScript
* HTML5
* CSS3
* Fetch API
* REST APIs
* JSON

## How to Run

1. Download or clone the repository.
2. Open the project folder in Command Prompt.
3. Install the required dependencies:


npm install


4. Start the development server:


npm start


5. Open the application in your browser:


http://localhost:3000


## How to Use

1. Select an HTTP method.
2. Enter the API URL.
3. Add request headers if required.
4. For POST, PUT, or PATCH requests, enter a JSON request body.
5. Click Send.
6. View the API response, status, and response time.
7. Use **Format JSON** or **Copy** when needed.
8. Previously sent requests can be accessed from **Request History**.
